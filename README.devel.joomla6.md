# J2XML Joomla 5/6 Modernization — Developer Notes

This document records the scope of the modernization work done in the
**4.0.0 release** and the quantitative comparison between the original
upstream codebase (`v3.10.233`, the last published release by Helios
Ciancio) and the current fork.

---

## Scope

The 4.0.0 release is a **breaking-change major release** that drops
Joomla 3 support entirely and targets **Joomla 5/6 + PHP 8.4+ only**.

The work covered three areas:

1. **Joomla 5/6 deprecated API migration** — `Factory::getDbo()`,
   `Factory::getUser()`, `Factory::getDate()`, `Factory::getDocument()`,
   `Factory::getLanguage()`, `Factory::getConfig()` replaced with
   container-based or application-based equivalents throughout the
   codebase (80+ occurrences).

2. **Joomla 3 compatibility shim removal** — deleted the entire
   `plugins/system/j2xml/layouts/joomla/` jQuery-based layout directory,
   `plugins/system/j2xml/src/joomla/` J3 `JLayoutFile` alias shims, and
   `plugins/system/j2xml/src/J2xml/Helper/Joomla.php`. Removed the
   `onBeforeCompileHead` jQuery loader and inline jQuery `onclick`
   handlers.

3. **PHP 8.4+ modernization** — `array()` → `[]`, `strpos() === false`
   → `str_contains()`, removed manual `LIBXML_PARSEHUGE` define, replaced
   `JObject`/`JHtmlSidebar`/`JLayoutFile`/`JApplicationCms` with
   namespaced equivalents.

See [`CHANGELOG.md`](./CHANGELOG.md) for the full list of changes and
[`README.TODO.deprecated.md`](./README.TODO.deprecated.md) for remaining
deprecated patterns scheduled for future removal.

## What this means for maintainers

1. **The core export/import engine is original.** The Table classes that
   do the actual XML serialization and database import are ~80% original
   code.  Bug fixes to the import/export logic should reference the
   upstream code for context.

2. **The entire UI/controller layer is new.** All controllers, models,
   views, dispatcher, and extension class are freshly written for the
   Joomla 5/6 MVC factory pattern.  These have no upstream equivalent.

3. **The jQuery dependency is gone.** All jQuery-based JavaScript and
   inline `onclick` handlers have been replaced with vanilla JS.  The
   `onBeforeCompileHead` method that loaded jQuery has been removed.

4. **Joomla 3/4 code paths are gone.** All `version_compare()` checks
   against Joomla versions, J3 layout shims, and J4-conditional branches
   have been removed.  The code assumes Joomla 5+ throughout.

5. **The test suite is new.** The upstream had no automated tests.  This
   fork has a Docker-based integration test suite with 82 tests covering
   export, import, round-trip, REST API send, and Joomla 6 compatibility.

## Copyright and authorship — best practice for this fork

### Current state

All 84 `@author` tags, all 84 `@copyright` tags, the LICENSE file,
and all 6 manifest `<author>` elements still attribute **only** the
original upstream author (Helios Ciancio).  No file in the codebase
marks the fork modifications or names the fork maintainer, despite
~65% of the codebase being new or substantively changed.

### GPL v3 requirements

The project is licensed under GPL v3 (or later).  Section 5(a)
requires that modified versions carry "prominent notices stating
that you modified it, and giving a relevant date."  The current
state — where modified files show only the original author's
copyright with no modification notice — does not satisfy this
requirement.

### Recommended changes

#### 1. Modified files (51 files that survived with changes)

Add a second `@author` and `@copyright` line alongside the original:

```php
 * @author      Helios Ciancio <info (at) eshiol (dot) it>
 * @author      Sven Gundestrup <sven@example.com> (fork modifications)
 * @copyright   Copyright (C) 2010 - 2026 Helios Ciancio. All Rights Reserved
 * @copyright   Copyright (C) 2026 Sven Gundestrup (Joomla 5/6 + PHP 8.4 fork)
```

#### 2. New files (74 files added by the fork)

Use the fork maintainer's copyright alone, with a "based on" note
where the file derives from upstream patterns:

```php
 * @author      Sven Gundestrup <sven@example.com>
 * @copyright   Copyright (C) 2026 Sven Gundestrup
```

#### 3. LICENSE file

Add a second copyright line:

```text
J2XML - Import/export solution for Joomla!
Copyright (C) 2010-2026 Helios Ciancio <info@eshiol.it>
Copyright (C) 2026 Sven Gundestrup <sven@example.com> (fork modifications)
```

#### 4. Manifest XML files (6 files)

```xml
<author>Sven Gundestrup (fork of Helios Ciancio's J2XML)</author>
```

#### 5. AUTHORS.md (new file)

Document both the original author and the fork maintainer:

```markdown
# Authors

## Original author
Helios Ciancio <info@eshiol.it> — original J2XML (v3.10.233 and earlier)

## Fork maintainer
Sven Gundestrup <sven@example.com> — Joomla 5/6 + PHP 8.4 modernisation (4.0.0+)
```

#### 6. README.md

Already has a fork notice ("Fork of eshiol/j2xml, modernised for
Joomla 5 and 6 with PHP 8.4").  This is sufficient.

### What NOT to do

- **Do not remove** Helios Ciancio's copyright from any file that
  derives from the original codebase.  GPL v3 §4 requires preserving
  copyright notices.
- **Do not change** the license.  GPL v3 (or later) is inherited
  from the original and must remain.
- **Do not claim sole authorship** of modified files.  The original
  author's contribution must remain credited.
